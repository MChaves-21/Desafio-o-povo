# 🎥 Landing Page: Barbie (2023)

Landing page responsiva feita como teste prático para a vaga de Aprendiz Front-end do **Grupo O POVO**. A página apresenta detalhes técnicos, elenco e resenhas do filme.

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (layout responsivo)
- JavaScript puro

## 🚀 Como rodar

Projeto estático, sem dependências:

```bash
git clone https://github.com/MChaves-21/Desafio-o-povo.git
cd Desafio-o-povo
```

Abra o `index.html` no navegador (ou use a extensão Live Server do VS Code).
